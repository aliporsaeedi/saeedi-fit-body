# Saeedi Fit Body

اپ اختصاصی شاگرد و پورتال مستقل مربی و مدیریت، با رابط فارسی و لوگوی رسمی برند.

رابط شاگرد و پورتال روی Cloudflare منتشر شده‌اند: [اپ شاگرد](https://saeedi-fit-body.aliisaeedi7116.workers.dev) و [پورتال مستقل](https://saeedi-fit-body.aliisaeedi7116.workers.dev/admin). دامنهٔ saeedifitbody.ir و زیردامنهٔ ادمین به Worker متصل شده‌اند، اما آخرین بررسی DNS هنوز فعال‌شدن دامنه را تأیید نکرده است.

بک‌اند و ثبت اطلاعات اصلی فعلاً از Google Apps Script و Google Sheets استفاده می‌کنند. D1 حاوی کپی آزمایشیِ تطبیق‌داده‌شدهٔ 64 تب است؛ خروج کامل از گوگل، OTP، PWA و همگام‌سازی آفلاین هنوز انجام نشده‌اند. وضعیت دقیق در [گزارش انتقال](CLOUDFLARE-MIGRATION-STATUS.md) ثبت شده است.

## ساخت و آزمون

به Node.js 24 یا جدیدتر نیاز دارید.

```sh
npm ci --ignore-scripts
npm ci --prefix design/lovable-ui --ignore-scripts
npm run build:lovable
npm test
```

ساخت، رابط واقعی React را به LovableApp.html تبدیل می‌کند؛ فونت‌ها و دارایی‌های لازم در خروجی قرار می‌گیرند. فایل تولیدشده و کد ادمین به Apps Script منتقل می‌شوند. ابزارهای آزمون و پوشهٔ design به اسکریپت بارگذاری نمی‌شوند.

برای خروجی مستقل Cloudflare، `npm run build:cloudflare` را اجرا کنید. فایل‌های تولیدشده در `cloudflare/dist` قرار می‌گیرند و داخل Git ثبت نمی‌شوند. آزمون GitHub هر دو خروجی را بررسی می‌کند؛ انتشار خودکار یا دسترسی به داده‌های واقعی در آن وجود ندارد.

## استودیوی استوری و رسید

شاگرد عکس خود را انتخاب و قاب‌بندی می‌کند، چیدمان و اندازهٔ استوری/پست/مربع را انتخاب می‌کند و تصویر PNG با لوگوی رسمی می‌گیرد. عکس برای این کار روی دستگاه پردازش می‌شود؛ آپلود یا انتشار خودکار وجود ندارد. اشتراک‌گذاری با اقدام خود کاربر و در صورت پشتیبانی مرورگر انجام می‌شود؛ دانلود تصویر همیشه مسیر جایگزین است.

تعداد ست و حجم از ثبت‌های ExerciseLogs همان حساب خوانده می‌شود. برنامهٔ پیشنهادی به‌عنوان تمرین انجام‌شده شمرده نمی‌شود. کالری اختیاری و تخمینی است؛ مدت فعالیت و نوع تمرین باید مشخص شوند. منبع مدل عمومی MET: [Compendium 2024](https://pacompendium.com/conditioning-exercise/). این خروجی اندازه‌گیری دستگاه نیست. خروجی متحرک ویدئویی در این نسخه پیاده‌سازی نشده است.

## داده و انتشار

فایل‌های ورود، توکن‌ها و عکس‌های خصوصی نباید در مخزن ثبت شوند. .clasp.json و فایل‌های محیطی محلی هستند؛ اطلاعات سرویس‌ها در Script Properties نگهداری می‌شوند. انتشار Apps Script به حساب مجاز و پیکربندی محلی clasp نیاز دارد و به‌صورت خودکار از GitHub اجرا نمی‌شود.

گردش‌کار GitHub فقط ساخت و آزمون را اجرا می‌کند و به دادهٔ واقعی شاگردها دسترسی ندارد.

## لوگو و مجوز فونت

BrandLogo.html دارایی اصلی برند است. برای خروجی تصویر، نوشتهٔ لوگو با فونت Montserrat مشخص‌شده در SVG به مسیر برداری تبدیل می‌شود تا فونت جایگزین نشود. فایل اصلی تغییر نکرده است. مجوز فونت در design/brand-fonts/OFL.txt و فونت‌های رابط در فایل‌های مجوز پوشهٔ design ثبت شده‌اند.
